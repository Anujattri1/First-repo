# Titanium Army

Fan-made extreme science showcase with an integrated static admin dashboard.

## Dashboard

Open `dashboard.html` after deploying the site, or use the Admin Dashboard link in the site header.

Test administrator credentials:

- Email: `admin@titaniumarmy.test`
- Password: `Admin@123`

The dashboard is a browser-local demo: users, video entries, and content changes are stored in that browser with `localStorage`. Do not use the supplied credentials in a production system. A production version needs a real authentication service and protected server-side database/object storage.
